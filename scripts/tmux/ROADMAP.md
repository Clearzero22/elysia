## 📋 版本规划

### v1.1.0 - 用户体验增强 (预计 2026-02-28)

**目标**: 提升日常使用体验，减少摩擦

| 功能 | 描述 | 状态 | 优先级 |
|------|------|------|--------|
| 会话检测 | 已存在会话时询问 attach/recreate/quit | 🔲 待办 | P0 |
| `--quick` 模式 | 快速启动，只创建 3 个核心窗口 | 🔲 待办 | P0 |
| `--doctor` | 环境健康检查命令 | 🔲 待办 | P0 |
| ts 新建会话 | 在选择器中按 `n` 创建新会话 | 🔲 待办 | P0 |
| 会话信息 | ts 显示窗口数、路径、时间 | 🔲 待办 | P1 |

**实现步骤**:

```
1.1 会话检测 (2h)
├── 1.1.1 添加 check_session_exists 函数
├── 1.1.2 实现 prompt_user_choice 交互
├── 1.1.3 添加 --attach, --recreate 参数
└── 1.1.4 更新帮助文档

1.2 --quick 模式 (1h)
├── 1.2.1 定义 MINIMAL_WINDOWS 数组
├── 1.2.2 添加 --quick 参数解析
└── 1.2.3 条件创建窗口

1.3 --doctor (1h)
├── 1.3.1 检查 tmux 版本
├── 1.3.2 检查可选依赖
├── 1.3.3 输出诊断报告
└── 1.3.4 返回状态码

1.4 ts 新建会话 (2h)
├── 1.4.1 添加 [n] New 选项
├── 1.4.2 实现项目目录选择
├── 1.4.3 调用 tk 创建会话
└── 1.4.4 自动 attach

1.5 会话信息 (1h)
├── 1.5.1 获取会话元数据
├── 1.5.2 格式化预览输出
└── 1.5.3 添加时间戳显示
```

| 布局模板 | minimal / standard / full | 🔲 待办 | P1 |
| 自定义窗口 | 用户定义窗口名称和角色 | 🔲 待办 | P2 |

**实现步骤**:

